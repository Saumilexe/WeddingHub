Put a name on your invite

Upload the card, upload the guest list, drag the name box where you want it, and download one PDF per guest.

You’ll need: your invitation as a PDF, and your guest list as an Excel or CSV file.

1. Invitation PDF

File type: PDF (.pdf). Upload your finished invitation card. It can have one page or several.

You choose the page for each text box in step 3.

2. Guest names

File type: Excel (.xlsx or .xls) or CSV (.csv). Only the first sheet is read, and you don’t need a heading row. Set it up like this:

A: NameB: Ending (optional)
1Rahul PatelSarvo
2Meera ShahSajode

Column B is added to the end of the file name. You can also pick Sarvo or Sajode for each guest after uploading.

No names yet.

File name ending

3. Text boxes

Type {name} where each guest’s name should go. Anything else is printed the same on every card.

Each font in the list is shown in its own style. Fonts in the first group show Gujarati names correctly. For English-only fonts, Gujarati names fall back to Noto Sans Gujarati.

File type: .ttf, .otf, .woff or .woff2. Only needed if you don’t want the built-in fonts. For Gujarati text the font must include Gujarati letters.

Long text shrinks to fit its box. Make a box taller to allow bigger text.

4. Download

Choose your invitation PDF to see it here.
Click a box to select it. Drag to move it, drag the dot to resize, or use the arrow keys.
